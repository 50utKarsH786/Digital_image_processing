# Experiment 01: Basic Image Processing

## Aim
To perform basic image processing operations such as reading, displaying,
and converting a digital image to grayscale using MATLAB.

## Objective
- To understand how digital images are represented in MATLAB
- To perform basic operations on images using built-in functions

## Theory
Digital Image Processing involves manipulating digital images using
computer algorithms to improve image quality or extract useful information.
MATLAB provides an Image Processing Toolbox that includes functions such as
`imread`, `imshow`, and `rgb2gray` for basic image operations.

## Algorithm
1. Read the input image using `imread()`
2. Display the original image using `imshow()`
3. Convert the image to grayscale using `rgb2gray()`
4. Display the grayscale image
