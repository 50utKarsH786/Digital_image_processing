EXPERIMENT- Histogram Equalization Using MATLAB


AIM:To improve the contrast of a grayscale image by applying the Histogram Equalization technique using MATLAB.

Software Requirements : MATLAB R2020a 

Introduction:
Histogram Equalization is a widely used technique in digital image processing for contrast enhancement. It works by redistributing the intensity levels of an image so that the histogram of the processed image becomes approximately uniform. This results in better visibility of image details, especially in images with poor contrast.

Methodology
In this experiment, a grayscale image is taken as input and analyzed. The histogram of the original image is plotted to observe the distribution of pixel intensity values. Histogram equalization is then applied to the image, and the resulting image and its histogram are examined. A comparison between the original and equalized images demonstrates the effectiveness of the technique.

ALOGRITHM:
Load the input image into MATLAB.
Convert the image to grayscale, if required.
Display the original grayscale image.
Plot the histogram of the original image.
Apply histogram equalization to enhance contrast.
Display the histogram equalized image.
Plot the histogram of the enhanced image.

OBSERVATION:
1.The histogram of the original image is unevenly distributed.
2.After histogram equalization, the intensity values are more uniformly spread.
3.The contrast of the processed image is significantly improved compared to the original image.

RESULT:
Histogram Equalization was successfully implemented, and the contrast of the grayscale image was enhanced effectively.

CONCLUSION:
Histogram Equalization is an efficient and simple contrast enhancement technique. It plays a crucial role in improving image quality and is commonly used as a preprocessing step in many image processing and computer vision applications.
